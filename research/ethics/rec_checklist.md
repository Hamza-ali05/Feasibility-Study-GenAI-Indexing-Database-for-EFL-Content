# Ethics process checklist (CCCU REC)

This file is the operational checklist. Completing the software workflow does **not** replace REC approval.

- [ ] CCCU Research Ethics Committee application submitted
- [ ] Written approval received before contacting practitioners
- [ ] Participant Information Sheet given to each volunteer
- [ ] Signed consent stored on CCCU secure drive (not in Git)
- [ ] Withdrawal window (14 days) explained
- [ ] Audio kept only on approved storage
- [ ] Transcripts anonymised before coding
- [ ] 12-month deletion diary set

`research/ethics/consent_log.json` records *process* events in the prototype (pseudonym, timestamps). It must never contain real names.
